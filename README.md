# Cabinet Dr Houda Souradi — Gynécologie Obstétrique & Fertilité

Application web bilingue (Français / Arabe avec support RTL) pour le cabinet du **Dr Houda Souradi** à Agdal, Rabat.

## Démarrage rapide

```bash
npm install
npm run dev
```

Pour consulter l'aperçu sur mobile via le réseau local :

```bash
npm run dev -- --host
```

Pour compiler la version de production :

```bash
npm run build
```
